# SPA Messenger (Учебный проект Яндекс.Практикум)

Проект представляет собой мессенджер, разработанный в рамках учебной программы Яндекс.Практикум. Проект создан на основе кастомного фреймворка, который был представлен на курсе. Во втором спринте проект переписан на компоненты. Реализована валидация на странице регистрации. Добавлен Prettier и Eslint.
